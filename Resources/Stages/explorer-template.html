Sources, accuracy and how to use

Each stage is split from 2024_Full_Dash.gpx, supplied on the Desert Dash website. Checkpoint coordinates come from Maps-2025.pdf pages 3–6. They match the nearest GPX points within 3, 3, 30 and 89 metres respectively. These are not confirmed 2026 course files.

All original GPX points have elevation. The display is sampled at approximately 100 m, with grade calculated across approximately 200 m. Elevation is uncorrected; its datum and accuracy are unspecified. Ascent/descent use approximately 100 m sampling. Profiles use independent vertical scales. 3D height is exaggerated for visibility, and the curtain extends to a local elevation baseline, not sea level. Sparse original track sections are connected by straight lines.

Hover the elevation chart or map to see the same position in both views. Use the position slider or arrow keys for keyboard navigation. Drag the map to pan; drag the 3D profile to rotate and tilt. Scroll or use +/− to zoom. GPX downloads retain the full original point resolution and elevations. The HTML contains all route data and official map images and works offline. Official maps are schematic and do not carry a live position marker. The GPS map overlays your position on OpenStreetMap when online. Street-map requests identify this app for local files, use normal browser caching and fetch only the current viewport. No tile prefetch or offline tile downloads are performed.
